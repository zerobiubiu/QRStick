# QRStick · 码贴生成器

把「一个标题 + 一段内容」变成一张可打印的二维码标签：内容转成二维码，标题直接显示，
按毫米与 DPI 精确出图，导出 PNG / PDF / Word。**纯前端，零上传**，数据不出这台机器。

## 快速开始

```bash
bun install
bun run dev      # 开发服务 http://localhost:5173
bun run build    # 产物 dist/，可直接发布到静态托管（阿里云 ESA Pages，根路径）
bunx tsc -b      # 类型检查
bun run lint     # oxlint
```

## 能做什么

- **纸张**：A4 默认，另有 A5 / A6 / A3 / B5 / Letter 与自定义毫米尺寸；长宽比可直接填（`1:1.414`、`3:4`、`0.707`）；纵向 / 横向。
- **分辨率**：72 – 600 DPI 任填，决定导出像素密度（A4 300 DPI = 2480 × 3508 px）。
- **二维码**：边长（含静默区，毫米）、纠错等级 L/M/Q/H、静默区模块数；按整数像素 / 模块落地，绝不放糊。
- **标题**：黑体 / 宋体 / 楷体 / 等宽，字号、加粗、对齐、在二维码上方或下方、间距、行距；自动折行。
- **印刷标记**（可开关，会印进导出件）：四角裁切标记、色标条与规格读数、页边距参考虚线。
- **导出**：PNG（原像素）、PDF（一页一张标签，页面毫米尺寸与印张一致）、Word（标题是**可编辑文字** + 二维码图片）。
- **批量**：CSV 一行一条（第一列标题、第二列内容），自动识别 UTF-8 / GBK，含表头，可下载示例；批量出多页 PDF / Word 并报进度。

| `docs/` | 文档中心（入口 `docs/README.md`） |

## 两条硬约定

1. **毫米是版面真相，像素是导出真相**：换算只发生在 `src/lib/units.ts`，不引入隐式换算。
2. **预览与导出同源**：只有 `src/lib/render.ts` 一个渲染核，不要在别处再画一遍标签。
