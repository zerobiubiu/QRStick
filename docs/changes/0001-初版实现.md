## 背景

需要「码贴生成器 QRStick」：输入标题与内容，出一张可打印的二维码标签；尺寸默认 A4 且可自定义（长宽比、分辨率、二维码边长、标题格式），内容转二维码、标题直接显示，导出图片 / PDF / Word。使用场景是车间与仓储贴标，纯前端、数据不出浏览器，部署到静态托管。

## 方案

- 技术栈：Vite + React 19 + MUI 9（含 MUI X DataGrid）+ TypeScript，纯前端静态站。
- 渲染：自绘 canvas 渲染核（见架构文档），预览与导出同源。
- 导出：PNG（原像素）、PDF（逐页无损）、Word（标题可编辑 + 二维码图片）。
- 批量：CSV 一行一条（第一列标题、第二列内容），自动识别 UTF-8/GBK，批量出多页 PDF 或 Word。
- 界面语言：印刷工单与印张（见决策文档）。

## 执行验证记录

- 执行环境：Windows 10.0.26300 x64；bun 1.4.2；Node 24.21.0；Chromium（headless，1440×900 与 390×844）；Vite dev server `http://localhost:5173`。
- 验证命令与实际输出：

| 命令 / 动作 | 实际输出 | 结论 |
| --- | --- | --- |
| `bunx tsc -b` | 无输出（0 错误） | 类型通过 |
| `bun run build` | `✓ built in 790ms`；`dist/assets/index-*.js 1,902.72 kB │ gzip: 582.99 kB` | 生产构建通过 |
| 浏览器打开首页 | 顶栏 / 工单 / 印张 / 读数条齐全，控制台无错误 | 界面可用 |
| 把分辨率切到 600 | 读数条变 `600 dpi · 4961 × 7016 px`，画布重排 | 参数→版式链路通 |
| 改二维码内容为长链接 | 读数 `59.0 mm · 17 px/模块 · 41 模块`（版本自动升） | 二维码自适应 |

| 标题加长 | 读数 `2 行 · 32 pt` | 折行生效 |

| 批量导出 4 行 PDF | 状态行依次 `付印 PDF 2/4…` → `4/4…` → `已导出 库位 A-03-12-4张.pdf · 4 页`；耗时 9.5 s | 批量流式导出 + 进度可用 |
| `impeccable detect --json src` | `[]` | 未命中设计禁区 |

- 已知限制：
  - PDF 用整页无损位图，300 DPI 下约 2.4 秒/页；批量很大时耗时可感知（有进度提示）。
  - 首页 JS 单包 1.9 MB（gzip 583 KB），其中 jsPDF/docx 占大部分；内网静态托管可接受，未做代码分割。
  - 未做打印纸张的物理校准（打印机自身缩放不在本工具范围）。
