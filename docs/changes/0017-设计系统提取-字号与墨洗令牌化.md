# 0017 · 设计系统提取：字号阶梯与墨洗四档令牌化

- 状态：已执行
- 影响范围：`src/theme.ts`、`src/index.css`、12 个组件/入口文件、`DESIGN.md`、`.impeccable/design.json`
- 前置文档：[0016-设计台账校正-引用改符号与侧车重生.md](0016-设计台账校正-引用改符号与侧车重生.md)
- 生效版本：**0.6.1**（行为级只有两处越阶字号收敛回阶梯；其余是同一视觉的令牌化）

## 背景（扫描：只找「用 3 次以上、同一意图」的重复与硬编码）

| 候选 | 证据 | 判定 |
| --- | --- | --- |
| **墨洗四档仍是裸值** | `rgba(16,16,16,0.035)` 散在 4 个组件（BatchPreviewGrid / BatchSource / BatchTable / fields），`0.02` 在 Docket，`0.05` 在 BatchTable；四档里只有 hover 档在 theme；CSS 变量层完全没有它们 | **提取**（DESIGN.md 明写「墨洗只有四档、按职责选」，却没有任何 token） |
| **字号阶梯写在代码里** | `fontSize: 10.5` **31 处**、11 ×9、10 ×7、11.5 ×8、12 ×4、13 ×2、15 ×1 | **提取**（One Ramp Rule 说「只走八级、从不即兴加值」，没有 token 这条律就没法执行） |
| **阶梯外值真的混进来了** | `12.5` ×3（批量表/预览的空状态、ErrorBoundary）、`14` ×1（确认框标题）——人眼与 impeccable 探测器都没抓到 | **收敛**回阶梯 |
| 发丝线 / 强线 | 裸 `1px solid rgba(16,16,16,…)` 计数为 **0** | 已提取过，不动 |
| 等宽读数复合样式 | `fontFamily: MONO_FONT` 出现 27 处，但周边属性各不相同（有的带 color、有的带 lineHeight） | **不提取**（reference 的「同一意图」不成立；字体栈本身已是常量） |

## 方案

| 项 | 做法 |
| --- | --- |
| 墨洗四档 | `src/index.css` 增 `--tint-footer / --tint-band / --tint-hover / --tint-current`（注释直指 Four-Wash Rule）；`src/theme.ts` 的按钮悬停覆盖也改用 `var(--tint-hover)`；组件里 7 处裸值改成 `var(...)` |
| 字号阶梯 | `src/theme.ts` 导出 `FONT_PX`（wordmark 15 / body 13 / small 12 / label 11.5 / readout 11 / meta 10.5 / micro 10 / ruler 9）；组件写 `fontSize: FONT_PX.meta`，不再写裸数字 |
| 越阶值收敛 | `12.5 → FONT_PX.small`(12)、`14 → FONT_PX.body`(13)：按 One Ramp Rule「从不即兴加值」处理 |
| 迁移方式 | 一次性 codemod（**模式替换**，脚本在仓库外）：77 处替换 / 12 个文件，并自动把 `FONT_PX` 挂到各文件已有的 theme import 上 |
| 明确不做 | 不提取等宽复合样式（意图不同）；不合并 theme.ts 的 rem 阶梯与 `FONT_PX` 的 px（MUI 变体走 rem、`sx` 走 px 是既有分层，合并有行为风险，列为后续候选） |

**已知限制**：

- `theme.ts` 的 MUI 变体仍写 rem（如 `0.8125rem` = 13px），与 `FONT_PX` 的 px 是两套表示：合并需要先确认 MUI 对数字单位的行为，本轮不动。
- 侧车 `.impeccable/design.json` 的 `inkAlphas` 里仍是墨洗的字面值（面板渲染用），没改成 `var()` 名——改主题时要注意两处。
- 等宽复合样式（27 处）保持内联：周边属性不同，硬抽会做出没人用的组件。
- 本轮是模式替换而非逐处手术，改动面 12 个文件都靠 tsc/lint/test/build/detect + 计算样式抽查兜底（已全绿）。

## 后续验证建议

1. 新增组件时只用 `FONT_PX.*` 与 `var(--tint-*)`；review 时 `grep -rn "fontSize: *[0-9]" src/ | grep -v theme.ts` 应为空。
2. 想知道有没有视觉漂移：`impeccable detect --json <改动文件>`，再抽一个读数和一个分段带对一下计算样式。
3. 若将来要统一 rem/px 两套阶梯，先在一个小白页面（如确认框）上验证 MUI 对 `fontSize: 13` 的落地单位，再决定是否合并。
