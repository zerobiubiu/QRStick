## 背景

需求是把工作台做完整：图片导出要有格式选择与三种批量模式（逐张 / ZIP / 拼接）、批量编辑区要能伸缩可拖拽可多选、右侧要能同时看多张预览、顶栏要在正中切换制作模式。既有的批量表是 MUI X DataGrid（只读→可编辑、无拖拽、无列宽拖拽），导出只有 PNG 一种。

**勘察实测的两条既有问题**：① 行内「删」按钮实测 64×31px 塞在 46px 的列里 → 列头 62→67、滚动区 592→597 的横向溢出；② 制作模式切换在顶栏左侧，不是视觉中心。

## 方案与实施

### 一、图片导出（`exportImage.ts` + `runImage.ts`）

| 能力 | 实现 |
| --- | --- |
| 格式 | PNG / JPEG；JPEG 走「副本上铺背景色再编码」，**绝不改调用方画布**；质量与背景色可调 |
| 逐张 | 每张一个文件，文件名 `序号-标题.ext`（两位补零、`sanitizeFileName`），两张之间节流 140ms，单张失败只记 `failed` 不中断 |
| ZIP | 逐张编码后 `fflate.zipSync(level: 0)`（图片已压缩，不再重复压）打成一个包，并附 `清单.csv`（`序号,标题,内容,文件名`，UTF-8 带 BOM） |
| 拼接 | 网格 / 纵向 / 横向 + 列数（1–8）+ 间距（mm）+ 可选标题带；结果总像素 **≤ 4000 万**，超出等比缩小并回传 `scale` |
| 状态 | 三种模式都按页报进度（`逐张 3/12`、`打包 12/12`、`拼接 20 张`），每页让出一次事件循环，界面不卡 |
| 出处 | 页来自 `renderLabel(当前 config / 每行覆盖后的 config)`，与预览同核，**不存在预览缓存参与导出** |

设置面板放在工单新增的「导出」段（格式 / 质量 / 背景色 / 批量模式 / 拼接参数），顶栏按钮文案随格式变化（出片 PNG ↔ 出片 JPEG）。

### 二、批量编辑区（`BatchTable.tsx`，MUI Table + dnd-kit）

- **删除按钮溢出修复**：改为 29×29 的图标按钮放在 40px 格里，实测不再溢出（`deleteOverflows: false`）。
- **拖拽排序**：`@dnd-kit/core + sortable`，行首 `DragIndicator` 手柄（悬停提示「拖动排序」），6px 距离阈值避免点复选框/输入框误触发，`DragOverlay` 给拖动中反馈，`restrictToVerticalAxis` 锁轴。排序后行号整体重排，且**选中行与多选会跟着搬位置**（`remapAfterMove`），因此数据顺序、预览绑定、选中态三者不会错位。
- **列宽拖拽**：表头右缘 9px 分隔条（`role="separator"` + `zIndex: 6`，没有它会被相邻表头盖住而点不到），宽度持久化到 `qrstick.view.v1`，各有最小宽度。
- **窗口化渲染**：行高固定 44px，超过 60 行只渲染视口内的行（上下占位行撑高度），几千行也不卡。
- **多选与批量操作**：每行复选框 + 表头全选（含半选态）、「已选 N 行」「删除选中」「取消选择」。
- **删除确认**：单行 / 多行 / 清空数据 / 删预设统一走 `ConfirmDialog`，逐条列出对象（超过 8 条折叠为「等共 N 项」），有取消与明确后果说明。
- **容器伸缩**：批量区用可拖拽分栏（数据表 | 分隔条 | 预览），比例在 store 里（0.25–0.75）并持久化，分隔条支持左右方向键微调。

### 三、多图预览（`BatchPreviewGrid.tsx`）

- 两种排布：**单张突出**（居中放大 + 上一张/下一张 + 尺寸读数）与 **多张网格**（`auto-fill minmax(168px,1fr)`），区域内独立滚动。
- **绑定稳**：每格内容完全由当前 `rows` 里那一行推导（标题 + 内容 + config 指纹），无过期缩略图缓存。
- **懒渲染**：`IntersectionObserver` 进视口才渲染、离开即释放；超过 200 张只预览前 200（导出的仍是全部）。
- 空态指向上游导入、单格失败只影响那一格并写明第几行、未渲染格显示占位不跳版。

### 四、制作模式切换（`App.tsx`）

- 顶栏改成 `minmax(0,1fr) auto minmax(0,1fr)` 三栏网格，模式切换在中间那栏恒定居中；实测中心 720 = 视口中心 720。
- 模式控件加大（高 35px、字号 13、加粗、选中反白）以体现「两种制作模式」而非普通筛选。
- 两种模式各自排布：单张 = 工单 + 整张印张（刻度尺/套准十字/读数条）；批量 = 数据表 + 多图预览。
- 模式状态全在 store：`config / rows / selectedRow / selectedIds / previewLayout / splitRatio / columnWidths / imageExport`，切模式不丢。
