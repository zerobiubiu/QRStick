- 状态：已执行

- 前置文档：[0007-复核修复与批量能力扩展.md](0007-复核修复与批量能力扩展.md)

## 背景

第 0007 批已经能「保存规格预设」，但只在本机、只有一种粒度。用户追加需求：**能保存样式预设，且样式预设可以导入导出**。这条同时解掉第二次评审里点名的一处硬伤——内网多台机器各存各的 localStorage，换台机器等于从零开始。

## 方案

### 一条预设列表，两种存档范围

| 范围 | 存什么 | 套用时 |
| --- | --- | --- |
| **整套**（`full`） | 全部参数（纸张 / 方向 / DPI / 边距 / 版式站位 / 二维码 / 标题格式 / 印刷标记 / 内容） | 整份替换当前配置 |
| **只样式**（`style`） | 标题格式 + 二维码参数 + 印刷标记 + 版式站位（**不含纸张、方向、DPI、页边距**） | 只覆盖这四组，纸张与页边距保持当前值 |

「只样式」的意义：同一套标题与二维码规格要贴到 A4 工单和 60×40 贴纸两种纸上，不必存两份、也不必每次重填 15 个字段。两种范围都存在同一条列表里，行内标注「整套 / 只样式」，套用时按范围生效。

### 预设文件（导入导出）

文件形状固定、带版本，且**故意宽容**：

```json
{
  "app": "qrstick",
  "kind": "presets",
  "version": 1,
  "exportedAt": "2026-10-09 17:05:00",
  "presets": [{ "name": "A4 工单", "scope": "full", "savedAt": "…", "config": { … } }]
}
```

- 导出：本机全部预设 → 一个 JSON 文件（文件名 `qrstick-预设.json`，走共用的文件名清洗），**不写入内部 id**（id 是本机概念，不该跨机器传播）。
- 导入：接受上面这份信封；也接受裸数组（`[预设…]`）或整份就是一份配置的裸对象；缺字段按默认值补齐（前向/后向兼容）；结构不对的条目**跳过并记一条提醒**，而不是整份文件失败。
- 合并规则：**同名覆盖**，新名字插到列表最前；因此同一份文件重复导入是幂等的（第二次报「新增 0、覆盖 N」）。
- 结果与失败都在预设段里就地给一行提示（导出套数 / 导入新增与覆盖数 / 首条提醒 / 失败原因）。

## 执行验证记录

- 执行环境：Windows 10.0.26300；bun 1.4.2；Chromium（headless，1440×900）；`bun run dev`。
- 验证动作与实际输出：

| 动作 | 实际输出 | 结论 |
| --- | --- | --- |
| `bunx tsc -b` / `bun run build` | 0 错误；`✓ built in 811ms` | 类型与构建通过 |
| 存两套（先整套、后样式） | 本机记录：`样式-40左常规:style:qr40:alignleft:boldfalse`、`整套-A4:full:qr60:aligncenter:boldtrue`；提示「已保存『样式-40左常规』」 | 范围与内容都对 |
| 选贴纸纸张 | `label-60x40 60×40` | 贴纸预设按其标注方向落纸 |
| 改成另一套样式（QR 80 / 右 / 加粗）后套用「样式-40左常规」 | 套用前 `paper=label-60x40 60×40 qr=80 align=right bold=true` → 套用后 `paper=label-60x40 60×40 qr=40 align=left bold=false` | **纸张被保留、只样式被覆盖** |
| 导出预设文件 | 1884 字节；`app=qrstick / kind=presets / version=1`；两条 `样式-40左常规:style`、`整套-A4:full`；`config` 形状完整；**不含内部 id**；提示「已导出 2 套预设（JSON，可带到别的机器导入）」 | 文件可带走 |
| 清空后用该文件导入 | 恢复 2 套（`整套-A4:full:qr60`、`样式-40左常规:style:qr40`）；提示「导入 2 套（新增 2、覆盖 0）」 | 导入回来一致 |
| 再次导入同一文件 | 提示「导入 2 套（新增 0、覆盖 2）」，总数仍为 2 | 幂等，不产生重复 |
| 导入坏文件（`{不是 json`） | 提示「导入失败：不是合法的 JSON 文件」 | 失败可见且人话 |

- 已知限制：
  - 预设文件只有 JSON 一种格式（这是数据交换文件，不做 CSV/XLSX 变体）。
  - 「只样式」覆盖的是四组（标题格式 / 二维码参数 / 印刷标记 / 版式站位），不含纸张、方向、DPI、页边距——**这是刻意的**，否则样式预设会连带改掉纸张尺寸。
  - 预设仍是本机存储（`qrstick.presets.v1`），没有云端或账号同步；跨机器靠导出/导入文件。
  - `DESIGN.md` / `.impeccable/design.json` 自 0007 起已落后于代码（导出说明条、样式预设段、可编辑表格、`!important` 焦点策略均未进记录）。
