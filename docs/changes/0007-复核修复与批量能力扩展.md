- 生效版本：**0.2.0**（三项新功能 + 批量能力扩展 → minor）

## 背景

第二次设计评审（同口径独立评审，分数 29 → 27）给出 4 条 P1 + 1 条 P2，并指出上一轮我自己引入的一处回归。用户选择：四条问题全部按推荐方案处理、三项新功能按顺序实现；随后追加需求「批量导入不止 CSV，且表格要能像普通二维表一样编辑」。

## 方案

### A. 回归修复（上一轮引入）

| 项 | 修法 |
| --- | --- |
| 同一条提醒同屏出现两次（体检区 + 状态行） | 状态行负责第一条原因，体检底栏只列其余条目；只有一条时不再重复渲染 |
| 整数模块取整可能**加长**（76×29 = 2204px = 186.6mm > 版心 185.9mm），且空间不足时二维码被挤成左贴 | `renderQrCode` 的取整只允许「不超过」上限：向上取整越界时改用 `floor`，保证落地边长 ≤ 空间上限，居中逻辑随之成立 |

### B. 评审 P1 / P2

| 项 | 修法 |
| --- | --- |
| P1 边长三级口径（字段 60 / 读数 58.9 / 纸面码面 42.7） | `LabelLayout` 拆出 `qrActualMm`（外框，含静默区）与 `qrInkMm`（码面）；读数条同时给两个数；字段 hint 说明「含静默区，码面才是贴纸上那个黑方块」 |
| P1 键盘焦点不可见（MUI 的 `outline: 0` 覆盖全局 `:focus-visible`，约 20 个控件无焦点环） | 全局焦点规则加 `!important` 并注明原因（组件库重置晚于本文件注入）；Tab 走查 8 个停靠点全部 `outline: 2px solid` |
| P1 最高风险动作只有 tooltip 一种解释途径 | 顶栏下新增**常驻导出说明条**（按模式切换文案，含「打印请设 100%，关闭『适应页面』」）；PDF 导出成功后状态行追加同一句话；`marks.colorBar` 默认打开，让纸面能自证尺寸 |
| P2 默认版式 67% 空白纸、无贴纸尺寸预设 | `PageConfig.blockAlign`（顶部/居中/底部，**默认居中**）+ 贴纸预设（60×40 / 80×50 / 100×150 / 4×6in）；选预设同时复位方向，预设按其标注方向落纸 |
| P1 批量模式是二等公民 | 批量数据源提到工单最前（模式即优先级）；空态文案改成指向「批量数据源」；导入的数据行与解析信息**落到本机**（刷新不丢） |
| （评审小观察）清空数据不可恢复 | 二次点击确认（按钮文案变「再点一次清空」），不引模态 |

### C. 三项新功能（按用户指定顺序）

1. **键盘快捷键**：`Alt+1` 出片 PNG / `Alt+2` 付印 PDF / `Alt+3` 交版 Word / `Alt+M` 切模式；在输入框内打字时不抢键；快捷键写进按钮 tooltip 与模式切换的 `aria-label`。
2. **保存规格预设**：`localStorage['qrstick.presets.v1']` 存 `{ id, name, savedAt, config }`；工单里新增「预设」段（存当前这套 / 套用 / 删除）；下次一键回到同一规格，解决「同一种标签每天重建 15 个字段」。
3. **批量表就地编辑**：标题/内容列可编辑（双击进入，Enter 提交、Esc 取消），`＋ 新增一行`，每行 `删`（自动重排序号并修正选中行）；改动即时写回 store 与本机存储，右侧印张预览跟随选中行刷新。

### D. 批量导入格式扩展（追加需求）

`src/lib/csv.ts` → **`src/lib/importData.ts`**（同一条链路，按文件类型分派）：

| 格式 | 处理 |
| --- | --- |
| CSV / TXT | 分隔符自动嗅探（制表符 / 逗号 / 分号 / 竖线，引号外计数），手写 RFC4180（引号包裹、字段内换行、`""` 转义） |
| TSV | 强制制表符 |
| JSON | 顶层数组：对象数组（键当表头）或二维数组；非法结构给明确报错 |
| XLSX | `read-excel-file`（MIT，纯 JS）读**全部工作表并只取第 1 张**，多表时提醒；数字/日期按文本落格 |
| 粘贴 | Excel 复制出来就是制表符分隔，复用同一条解析路 |
| 编码 | 先 UTF-8，出现替换字符改 GBK（中文 Windows 的 Excel 另存 CSV 默认 GBK），去 BOM |
| 老式 `.xls` | 明确拒绝并提示「另存为 xlsx 或 csv」 |
