# 0002 · 包管理器从 npm 切到 bun

- 状态：已执行
- 影响范围：依赖安装与脚本命令（`package.json` 不变，锁文件与命令变）
- 前置文档：[0001-初版实现.md](0001-初版实现.md)
- 生效版本：0.1.0（未改动程序行为，不递增版本）

## 背景

用户明确要求：包管理一律用 bun，不用 npm。本项目此前用 `npm install` 安装依赖，仓库里留的是 `package-lock.json`。

## 方案

- 删除 `package-lock.json`，删掉 `node_modules` 后用 `bun install` 全量重装，得到 `bun.lock`。
- 命令统一改为：`bun install` / `bun add <pkg>` / `bun run dev|build|lint|preview` / `bunx <cli>`。
- `.gitignore` 补上其它包管理器的锁文件（`package-lock.json`、`yarn.lock`、`pnpm-lock.yaml`），避免再次混入。
- 规则写入项目 `AGENTS.md`（包管理与命令一节）。

## 实施（改动文件清单）

| 文件 | 改动 |
| --- | --- |
| `bun.lock` | 新增（依赖锁定） |
| `package-lock.json` | 删除 |
| `.gitignore` | 新增：屏蔽其它锁文件、`.impeccable/` 过程产物 |
| `AGENTS.md` | 新增：包管理器与命令规则 |
