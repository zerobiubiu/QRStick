## 背景（先看真实首访）

按 `/impeccable onboard` 的口径先取证：清空本机存储后重开，实测首访是**一张完整的示例标签**——标题「库位 A-03-12」、真二维码、A4 300 DPI，读数条与体检都正常，点一次「付印 PDF」就能拿到可打印文件。也就是说 aha 路径本来就短（一次点击），问题不在「教产品」，而在三处说实话的方式：

| # | 缺口 | 取证 |
| --- | --- | --- |
| 1 | **示例没被标注成示例**：它看起来像用户自己的数据，改不改、能不能直接印没人说 | 首访页面里没有任何「这是示例」的字样；`PRODUCT.md` 反而明确要求「示例必须标注为合成数据」 |
| 2 | **快捷键从不出现在界面上**：Alt+1/2/3、Alt+M 只在顶栏按钮的 tooltip 里 | 首访文本里搜不到任何 Alt 提示；车间里「同一动作重复几十次」正是它的价值场景 |
| 3 | **首次导出之后的下一步没有接住** | 状态行只报文件名与页数，「拿去打印」的提示只写在页面上方那句动作说明里 |

用户画像与时间预算由 `PRODUCT.md` 给定：车间/仓储一线、站在工位旁、几十秒要拿到能贴的标签。所以引导必须**不占流程**：不加 modal、不做 tour、不新增教程模式。

**明确不做**：不做 spotlight 分步引导（对一线工具偏重，也与「没有『应用』这一步」的克制语言冲突）；不重排工单段序（预设段在首位是 0008 的既有设计）；不改默认参数值本身（预填就是最有说服力的「示例」）。

## 方案

| 项 | 做法 |
| --- | --- |
| 一次性上手条 | 印张列顶部加一条与工单同构的一行条：虚线标记 + 10.5px 次级墨一句「示例标签：把工单里的标题与内容换成你的，点「付印 PDF」出来的就是能直接打印的 A4 标签」+ 右侧「知道了」文本按钮。**只在 `record.phase === 'idle'` 时出现**；点「知道了」或**第一次导出成功**都收起，并写入本机记忆（`ViewState.onboardSeen`）——同一台机器不再出现，回头用户不会被再教育 |
| 示例标注 | 体检里加一条 `warn`：标题与内容**都还是出厂示例**时提醒「当前是示例数据（库位 A-03-12 / LOC-A-03-12）：换成你自己的编号再出片。」改掉任一处即消失——是「有提醒」（虚线）而不是「参数有错」（不拦导出） |
| 快捷键可见性 | 状态行空闲时右侧摊一行「Alt+1 出片 · Alt+2 付印 · Alt+3 交版 · Alt+M 切模式」（10.5px 等宽次级墨），一有导出记录就让位；窄屏按优先级塌缩（`xs` 不显示），不挤印张 |
| 本机记忆 | `onboardSeen` 进 `ViewState` 并随 `qrstick.view.v1` 持久化；读取时**只有明确存过 `true` 才算收过**——老配置（没有这个字段）保持「未收」，升级后的老用户也能看到一次首访条；写入失败走既有 `PersistStatus` 口径（仅内存内生效，不报错） |

**已知限制**：

- 上手条只在 `record.phase === 'idle'` 出现：如果用户在首访时**先**点了导出，它会直接收起（这正是设计意图，但意味着「先点后读」的人不会再看到那句示例说明）。
- 示例标注比对的是**出厂默认值**：用户如果把标题/内容改成与默认完全相同的字符串，标注会（正确地）不出现。
- 本机存储被禁用时，`onboardSeen` 只在本次会话内生效——刷新后上手条会再次出现；这是隐私模式下所有本机记忆的共同代价（0013 已把存储失败做成可见提示）。
- 上手条文案是固定中文单行，未做多语言（本项目为单语工件，界面语言即印刷工单中文）。

## 后续验证建议

1. 找 1–2 位真实使用者看首访：记录「从打开到点出第一份 PDF」的秒数，以及是否有人点「知道了」之前就自己改了标题（后者说明上手条可以更短）。
2. 若上手条被大量直接关掉：把它降级成状态行里的一句（与快捷键提示并列），而不是单独占一行。
3. 快捷键提示的命中率值得单独看一次：如果没人用 Alt+1/2/3，说明「同一动作重复几十次」的场景其实没发生，再考虑撤掉这行。
4. 后续若要加新引导，沿用同一条纪律：**只在 idle 出现、点掉或到过价值即收起、存本机不再出现**。
