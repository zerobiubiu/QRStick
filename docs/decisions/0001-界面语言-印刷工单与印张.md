# 0001 · 界面语言：印刷工单与印张

- 状态：已执行
- 影响范围：全部界面（`src/theme.ts`、`src/index.css`、`src/components/*`、`src/App.tsx`）
- 前置文档：仓库根 `PRODUCT.md`
- 替代文档：无
- 生效版本：0.1.0

## 背景

产品要一套自己的界面语言。这个类目的默认做法是「左侧参数表单 + 右侧白底预览 + 顶上一排导出按钮」，蓝色主色——能用，但谁做都是这样，界面不会替用户回答「我这台机器在干什么」。

## 决策

界面语言定为**印刷工单与印张**：一块台面上摊着一张待付印的印张，旁边夹着一张联单工单。

选的不是皮，是把机制摊开：这个工具真实的机制就是「参数 → 印张 → 交付文件」，印刷车间用了几十年的工单正好是这个对应关系。

落地语法（都在代码里有对应实现）：

| 语法 | 落点 |
| --- | --- |
| 字段名 : 值 的格 | `FieldRow`，全站唯一的参数输入形态 |
| 联单分段（规格 / 标题 / 二维码 / 数据 / 体检） | `DocketSection` |
| 毫米刻度尺贴着印张测量 | `SheetRuler`，按当前每毫米像素现算，刻度不是装饰 |
| 四角套准十字（四色） | `RegistrationMark`，钉住看版台四角 |
| 色标条与规格读数（印在导出件上） | `render.ts` 的 `drawColorBar`，真读数 |
| 状态只用线型表达 | `LineMark`：实线已生效 / 点划线出片中 / 双线已导出 / 虚线有提醒 |
| 参数按优先级塌缩 | 窄屏收起「更多规格」，预览与导出永不被挤掉 |

四条纪律来自被否掉的四个方向，落进实现而不是落进口号：

1. 状态不靠颜色（来自「发射线校准轨」）→ 全站状态用线型。
2. 参数按优先级塌缩、破坏性动作隔离（来自「深色工作台」）→ 「恢复默认」单独一行放在工单底部并带说明。
3. 毫米刻度尺是一等公民（来自「拉班舞谱」）→ 刻度尺 + 读数条。
4. 表头钉住当前可见范围（来自「词典肩标与图版」）→ 批量表头实时报「第 X–Y 条 / 共 N 条」。

## 被否掉的方向与理由

| 方向 | 判定 | 理由 |
| --- | --- | --- |
| 网格构造样本 | 备选 | 毫米↔模块的换算看得见，但字体样本是设计人群的世界，车间一线不认 |
| 登机牌与航班板 | 备选 | 分段票据=标签解剖，变更点亮对批量是真需求；认同感弱于指派方向 |
| 发射线校准轨 | 否 | 光谱仪读数语言与现场无关；彩线细线与黑白打印诉求相反（吸收了线型状态） |
| 深色工作台 | 否 | 车间明亮，深色底反功能（吸收了塌缩与隔离） |
| 拉班舞谱 | 否 | 垂直时间流与双侧对称找不到对应物（吸收了毫米刻度尺） |
| 词典肩标与图版 | 否 | 阅读世界的认同感与现场无关（吸收了可见范围读数） |
| 品类标准做法 | 出口 | 保留为安静出口，未采用 |

## 后果与风险

- 印刷标记必须做成真功能（裁切/出血/边距/读数），否则会退化成装饰——这一条写进了 `render.ts` 的实现纪律。
- 纸白 + 墨黑容易滑向复古怀旧：界面不使用做旧纹理、不引用旧字形，现代工单的克制是底线。
